# Should a new market learn from other markets?
Cross-market next-destination recommendation on the Booking.com Multi-Destination Trips dataset

Business Intelligence (Prof. Jason J. Jung), Chung-Ang University, Fall 2026: individual term project
Author: Aye Thadar Soe

## What this project does
For each booker-country market in the Booking.com dataset, it compares next-city recommenders trained on
(a) that market's own trips, (b) all markets pooled together, and (c) a validation-tuned blend of the two.
A simulated market-entry experiment then separates the effect of market size from the effect of how
distinctive the market's travel behaviour is.

## How to run
1. Install Python 3.10+ and the packages:
   ```bash
   pip install -r requirements.txt
   ```
2. Download the dataset. It is **not redistributed here**, following the dataset terms:
   ```bash
   git clone https://github.com/bookingcom/ml-dataset-mdt.git data_repo
   ```
   The notebook expects `data_repo/train_set.csv`, `data_repo/test_set.csv` and `data_repo/ground_truth.csv`.
3. Run the notebook:
   ```bash
   jupyter notebook analysis.ipynb        # interactive, or:
   jupyter nbconvert --to notebook --execute --inplace analysis.ipynb
   ```
   Runtime: about 2.5 minutes (tested on Python 3.13, pandas 3.0, numpy 2.5, matplotlib 3.11).
   All random steps use fixed seeds, so results are reproducible.

## Evaluation protocol (short)
- Official split: train = 217,686 trips; test = 70,662 trips whose final city is hidden (`ground_truth.csv`).
- The blend weight α is tuned per market on a validation split (the final city of a random 10% of
  *training* trips). The test set is used only once, for the final evaluation.
- Metrics: Recall@4 (the challenge's accuracy@4), NDCG@4, item coverage; 95% bootstrap confidence
  intervals (1,000 resamples; paired for model differences).
